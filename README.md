# Food Tracker API & DashBoard
Food Tracker е уеб приложение, разработено като проект за избираема дисциплина Introduction to Python.
Целта му е да позволява записване, категоризиране и анализ на покупки и храни, с фокус върху чист Python код, асинхронен backend и визуален dashboard.

Проектът е разделен на REST API (backend) и Streamlit dashboard (frontend), които комуникират чрез HTTP заявки.

## Основни функционалности

### Потребители

 - Регистрация и вход (OAuth2 Bearer Token)
 - Защитени API крайни точки
 - Роли: потребител и администратор
 - Демонстрационен потребител и seed данни

### Категории

 - Глобални категории
 - Персонални категории
 - CRUD върху категории

### Записи за храни/покупки

 - CRUD
 - Филтриране по: период, категория, тагове

### Dashboard

 - Месечна обща сума
 - Топ категории по разход
 - Последни 5 записа
 - Визуализация чрез Streamlit

## Инсталация и стартиране

### 1. Инсталиране на зависимости
 - Проектът използва `pyproject.toml` за управление на библиотеките. Инсталирайте всичко необходимо с:
 ```bash
   pip install ".[test]" streamlit requests
    ```

### 2. Стартиране на API сървъра
 - ```bash
      pip install fastapi 
 ```
### 3. Стартиране на Dashboard-a
 - в отделен терминал:
```bash
   streamlit run dashboard.py
   ```
